## Description

This project contains auxiliary scripts that can help me and others on future bigger projects. It also helped me consolidate a lot of the knowledge I gained through 42's C piscine.

Not all of the functions are included in the standard C library. Here's a brief summary of each of the functions:

* ### **Memory/bytes operations**
	- ```ft_memset``` - Fills ```n``` bytes within ```s``` with the character ```c```.
	- ```ft_memcpy``` - Copies ```n``` bytes from ```src``` to ```dest``` without the memory area overlapping.
	- ```ft_memmove``` -  Copies ```n``` bytes from ```src``` to ```dest```, the memory area may overlap.
	- ```ft_memchr``` - Parses ```n``` bytes inside ```s``` and returns the first instance of ```c```.
	- ```ft_memcmp``` - Returns the first discrepancy between ```s1``` and ```s2``` within the first ```n``` bytes.
	- ```ft_calloc``` - Memory allocates ```s``` and fills it with ```0```'s.
	- ```ft_bzero``` - Rewrites ```s``` and fills its bytes with ```0```.
* ### **Character classification**
	- ```ft_isalpha``` - Checks whether the argument given is an alpha character or not.
	- ```ft_isdigit``` - Checks whether the argument given is a digit character or not.
	- ```ft_isalnum``` - Check whether the argument given is an alphanumeric character or not.
	- ```ft_isascii``` - Checks whether the argument given is included in the ascii character table.
	- ```ft_isprint``` - Checks whether the argument given is a printable character.
* ### **String operations**
	- ```ft_strlen``` - Returns the length of the given string excluding the null character.
	- ```ft_strlcpy``` - Copies ```size - 1``` characters from ```src``` into ```dst```.
	- ```ft_strlcat``` - Appends ```dst``` chars into ```src``` from its end.
	- ```ft_strchr``` - Returns a pointer to the first element on ```s``` that matches ```c```.
	- ```ft_strncmp``` - Compares the first ```n``` bytes of ```s1``` and ```s2``` and returns the substraction of its chars if different or 0 if same.
	- ```ft_strrchr``` - Returns a pointer to the last element on ```s``` that matches ```c```.
	- ```ft_strdup``` - Duplicates the string given.
	- ```ft_strnstr``` - If ```little``` is inside ```big```, a pointer to the first match is returned, else ```NULL``` is returned.
	* ```ft_strtrim``` - Returns ```s1``` with ```set``` chars removed if on the sides of the string.
	* ```ft_split``` - Splits the characters within ```s``` based on the delimiter ```c``` and puts them inside a new string inside an array.
	* ```ft_strjoin``` - Concadenates ```s1``` and ```s2```.
	* ```ft_substr``` - Creates a substring from characters within ```s``` that start in ```start``` and ends in ```len```.
* ### **Transformations**
	- ```ft_toupper``` - Turns the uppercase character given into its lowercase.
	- ```ft_tolower``` - Turns the lowercase character given into its uppercase.
	- ```ft_atoi``` - Converts the string given into integer.
	.
	* ```ft_itoa``` - Turns integer values into a string of characters.
* ### **Function iteration**
	* ```ft_strmapi``` - Applies ```f``` (1st arg: index of s; 2nd arg: char of s) function to all the characters within ```s```, returning its result inside an array.
	* ```ft_striteri``` - Applies ```f``` (1st arg: index of s; 2nd arg: direction of char inside s) function to all the characters within ```s```.

* ### **File descriptor**
	* ```ft_putchar_fd``` - Sends the char given into the specified file descriptor.
	* ```ft_putstr_fd``` - Sends the string given into the specified file descriptor.
	* ```ft_putendl_fd``` - Sends the string given into the specified file descriptor, then sends a newline.
	* ```ft_putnbr_fd``` - sends the given integer into the specified file descriptor.

* ### **Linked lists**
	* ```ft_lstnew``` - Creates linked list through the new node.
	* ```ft_lstadd_front``` - Adds a new node to the beginning of the list.
	* ```ft_lstadd_back``` - Adds a new node to the end of the list.
	* ```ft_lstsize``` - Returns the length of the linked list.
	* ```ft_lstlast``` - Returns the last node of the linked list.
	* ```ft_lstdelone``` - Frees the memory of the given node.
	* ```ft_lstclear``` - Removes and frees the memory of the given node and its consecutive nodes inside the list.
	* ```ft_lstiter``` - Applies ```f``` function to all the nodes inside the given list.
	* ```ft_lstmap``` - Applies ```f``` function to all the nodes inside the given list and creates a list with the return values. Deletes the node with ```del``` if necessary.

### How to use
1. Build the project using ```make```.
2. Add the ```libft.a``` generated by make, into the directory where you want to use it.
3. Include the function to use with ```#include```

### Other make usages
- ```make clean```: Removes all generated ```.o``` files.
- ```make fclean```: Removes all generated ```.o``` files and ```libft.a```.
- ```make re```: Rebuilds everything.
